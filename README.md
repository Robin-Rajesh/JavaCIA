# ☕ Java CIA: Library Management System and Matrix Rotation

Java programs written for a continuous internal assessment (CIA).

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)

## 📚 Library Management System (`LibrarySystem.java`)

A menu-driven console app that demonstrates inheritance and encapsulation.

- **Classes:** `Book`, with the subclasses `ReferenceBook`, `FictionBook` and `Periodical` (which extends `ReferenceBook`)
- **Menu options:**
  1. View all books
  2. Borrow a book
  3. Return a book (overdue fine of 5 per day)
  4. View library statistics
  5. Exit

## 🔄 Matrix Rotation (`matrix.java`)

Reads a matrix of any size from the user and prints it rotated.

## 🚀 Running

```bash
javac LibrarySystem.java && java Main
javac matrix.java && java matrix
```
